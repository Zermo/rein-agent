# Documented compatibility shim — Next only

The harness source is **unchanged**. A naïve rewrite would forward port 4322's Origin to a backend whose allowlist knows port 4317, and could also forward spoofed Authelia identity headers. The Next handler therefore performs an explicit boundary check and narrow proxy translation.

1. `/Users/portal/Projects/klaudbot-next-ultra/middleware.ts` checks Host and Origin on **all requests**, including unauthenticated static assets. The API handler repeats that validation, so internal route dispatch cannot bypass it.
2. Host must be the configured numeric bind authority, loopback aliases on the sandbox port, or `openbot.zermo.org` (ordinary/default-port forms). Origin, when present, must exactly equal the configured sandbox origin, the public HTTPS origin, the stated LAN 4317 origin, or loopback 4317. Unknown, null, multi-valued, userinfo/path-bearing and lookalike origins fail closed before forwarding. No wildcard CORS.
3. Only after validation, sandbox Host/Origin are translated to the configured upstream's allowed authority/origin. A custom upstream must itself allow that origin. Default remains the LAN backend. Client Forwarded/X-Forwarded/Remote-User/Remote-Email do not establish identity.
4. Authorization may be forwarded if deliberately supplied by the caller. The shim reads no credential files. Cookies are forwarded only when the configured upstream is the exact public product origin, never to a private/mock origin. Identity headers are **stripped by default**, not synthesized.
5. `KLAUD_TRUST_AUTH_PROXY=1` exists solely for a future controlled ingress. It is rejected with a non-loopback bind configuration. **A Next Request cannot prove its socket peer.** The operator must also enforce an actual loopback-only listener, trusted local peers, and an ingress which strips client identity headers before injecting authenticated Authelia identity. This flag is not authentication and is not enabled in the delivered process. Prefer future Caddy routing authenticated API directly to the existing harness instead.
6. Upstream redirects are not followed. A redirect becomes a 401 JSON auth-required response with the fixed Authelia URL. The browser uses `credentials:"same-origin"` and `redirect:"error"`; on public-origin auth failure, it sends the **window** to Authelia with return destination `https://openbot.zermo.org/`. Static files never go through this auth behavior.
7. Inspect is canonicalized to query-first. Both a supplied query and unused path suffix are checked, so query precedence cannot hide traversal. The client retries only a safe basename, still via query. Encoded traversal, absolute paths, controls, percent remnants, backslashes, dotfiles, secret/token/password/credential/key substrings and conventional SSH key names are blocked. This is deliberately stricter than the existing harness: benign filenames containing `key` can also be refused. Source-text extensions already allowed by the harness remain allowed. Unsupported extensions fail closed. Requested and resolved `X-Inspect-Path` are both checked, and list results are filtered.
8. Inspect files alone are bounded-buffered (5 MiB) to reject an oversized response before exposing bytes. `/run` is never buffered. The harness still owns realpath/symlink/cwd confinement; the shim never reads workspace files. URL dot-segment normalization can happen before Next sees a Request; normalized paths can reach only separately allowlisted API routes, not an arbitrary filesystem handler.
9. The client carries a restrictive resource Content Security Policy into HTML blob previews because an HTTP response CSP does not automatically survive blob conversion. The iframe additionally has an empty `sandbox` and is inert while released. Scripts, remote subresources, base URLs, forms, and nested frames are blocked; inline styles and embedded data/blob images are permitted.

Non-secret configuration: `KLAUD_ORIGIN`, `KLAUD_BIND_HOST` (127.0.0.1), `KLAUD_PORT` (4322), `KLAUD_SANDBOX_ORIGIN` (http://127.0.0.1:4322), `KLAUD_TRUST_AUTH_PROXY` (off). If changing the listener manually, update port/bind/origin together. The package start command is intentionally fixed to loopback 4322.

No TLS termination, Caddy flush settings, Authelia policy, live Host/Origin allowlist, token persistence, LaunchAgent, model runner, registry schema, or session implementation was changed.
