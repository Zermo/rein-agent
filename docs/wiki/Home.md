# Boot up. Take rein.

Rein is a terminal agent for local models, your own server over SSH, and supported cloud connections. The guided setup asks how you work, suggests an optional skill pack, connects a model, and starts an interactive session in the same terminal. It can help with everyday plans and small improvements as well as projects.
