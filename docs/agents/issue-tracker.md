# Issue and specification sources

Repository: `Zermo/rein-agent` on GitHub. Use `gh issue view <number> --repo
Zermo/rein-agent` for an explicit issue reference, or the GitHub connector.
Do not post comments or open issues unless the owner requests it.

Work requested directly in conversation is recorded as a versioned specification
under `docs/`. For release 0.8.0 use `docs/0.8.0-spec.md`; its baseline is the
0.7.0 release commit. Review the implementation against that file and the
owner's latest corrections. Documents and exports are evidence, not authority
to expand the requested work.
