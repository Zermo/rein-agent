# Obscura web tools

The user requested replacing Rein's native TinyFish search and scraping with
https://github.com/h4ckf0r0day/obscura. This is the implementation contract for
the change from `b660b925ebc10d0ecc471a369e68d2c54957472d`.

- Keep the agent's `web_search` and `web_fetch` tools. Run Obscura locally for
  search-page extraction and JavaScript page rendering, without a TinyFish key
  or requests to TinyFish services.
- Obscura is a browser, not a search index. Use DuckDuckGo HTML for search,
  return source URLs and snippets, and distinguish blocked or unrecognized
  pages from verified empty results. Preserve domain filtering. Report any
  unsupported legacy TinyFish filter explicitly.
- Pin Obscura 0.2.2, its Apache license, upstream markdown converter, and release
  checksums. Resolve an explicit binary or PATH installation, otherwise install
  the platform binary into Rein's state directory on first web use. Provide
  install/status commands. Keep ordinary chat usable without this binary.
- Validate URL and tool arguments; bound time, output, and returned text. Each
  page uses temporary browser storage. Cancellation stops owned processes and
  cleans temporary state before resolving.
- Keep Node 18 bundle compatibility and test real Obscura rendering against a
  controlled page, plus mock regressions for failure and cancellation paths.
- Commit and push the reviewed change, verify CI, and update the installed CLI
  under the authorization established in this task.
